Over-The-Air Firmware Update

ℹ Arduino Bootloader OTA Update

This device uses the Arduino Portenta bootloader for safe OTA updates. Your firmware will be:

  1. Validated and stored to QSPI flash memory
  2. Bootloader configured via RTC backup registers
  3. Device reboots automatically
  4. Bootloader flashes the new firmware from QSPI storage

✓ Safe: The bootloader applies the firmware before your application starts, avoiding runtime conflicts. If flashing fails, the device will boot into the previous working firmware.

How to create firmware.ota:

  1. Build your project: pio run
  2. Navigate to tools folder: cd tools
  3. Compress firmware: python lzss.py --encode ../.pio/build/portenta_h7_m7/firmware.bin firmware.lzss
  4. Convert to OTA: python bin2ota.py PORTENTA_H7_M7 firmware.lzss firmware.ota
  5. Upload firmware.ota using the form above
  6. Device will reboot and apply the firmware

Note: The bootloader accepts both LZSS-compressed .ota files and raw .bin files. Format is auto-detected.
